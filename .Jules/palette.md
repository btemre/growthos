## 2025-05-15 - [Loading state for core Button component]
**Learning:** Implementing a reusable `loading` prop in the core UI library's `Button` component is the most efficient way to scale visual feedback for async operations across the entire application. It ensures consistent accessibility (via `aria-busy`) and reduces boilerplate in form components.
**Action:** When working on new forms or interactive elements, leverage the `Button`'s `loading` prop instead of manual spinner management to maintain UI consistency and accessibility standards.
