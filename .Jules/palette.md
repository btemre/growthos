## 2025-05-15 - Loading States for Buttons
**Learning:** Adding a `loading` prop to a core `Button` component provides a consistent and accessible way to handle asynchronous states across the application. It prevents double submissions by disabling the button and provides immediate visual feedback.
**Action:** Use the `loading` prop in the `Button` component for all submit actions and long-running processes. Ensure the spinner has proper spacing when labels are present.
