## 2025-02-18 - Calendar Grid and Event Map Optimization
**Learning:** In React components that render large grid structures (like a calendar with 35-42 days) or tables, executing array operations like `.filter()` with date helpers (e.g. `isSameDay`) in every loop iteration yields an $O(D \times E)$ nested loop bottleneck. Wrapping the grid array generation (`days`) in `useMemo` avoids redundant date math parsing on unrelated renders, and pre-grouping events into a `Map` keyed by formatted date string reduces grid lookup complexity to $O(D)$ with $O(1)$ lookups. Additionally, string key equality checks (`dayKey === selectedKey`) are faster than repeatedly instantiating/comparing `Date` objects.
**Action:** Always structure grid rendering loops to use O(1) Map lookups for associations, and avoid parsing/manipulating Date objects or generating static grids inside the hot path of the render loop.
