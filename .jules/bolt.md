## 2025-08-10 - [Render-phase State Sync & Auth Mount Initialization Issues]
**Learning:** Over-optimizing react hook states (such as auth initialization or form field presets) by converting mounting effects to render-phase state synchronization can lead to initialization failures. For instance, skipping `setBootstrapState("ready")` on mount when Firebase is already configured breaks user authentication completely because the initialization effect depends on `bootstrapState !== "loading"`. Furthermore, render-phase updates comparing `bootstrapState !== prevBootstrap` are skipped on initial render when both are `"loading"`, causing states like `authLoading` to remain stale and stuck in loading mode forever.
**Action:** Preserve mounting initialization effects for system-critical state bootstrap. For lists and filters, use `useMemo` with reference-stable primitive/stringified keys (e.g. `todayKey` string computed in render) to safely prevent redundant renders without resorting to complex and fragile render-phase state synchronization hooks.
