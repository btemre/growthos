## 2025-05-22 - Custom React.memo Comparison for Firestore Snapshot Mapped Items
**Learning:** In list and board components fetching data via Firestore client-side subscriptions (e.g., `subscribeDealsForUser` or `subscribeLeadsForUser`), the underlying callback maps over incoming `QuerySnapshot` documents to construct custom typed objects. Because of this, every subscription update triggers a mapping function that recreates object references for all list items, even unchanged ones. As a result, standard `React.memo` wrapper checks (which rely on shallow reference equality, `prevProps.item === nextProps.item`) will fail to prevent re-renders because the item reference changes.
**Action:** Always provide custom comparison functions to `React.memo` for items in mapped subscription lists. Compare the critical properties (such as `id`, `stage` or `educationStage`, `title` or `name`, `score`, and `ownerId`/`ownerLabel`) instead of relying on object reference equality.
