## 2025-07-18 - Server-side query subscriptions security rule matching
**Learning:** In a Firestore-backed application with strict collection security rules (e.g. tasks collection restricted to admin OR assignedTo matching the authenticated user), any query subscription must match the security rules. If a query requests fields without matching filters (e.g. non-admin querying relatedType/relatedId without filtering on assignedTo), the subscription will fail completely due to security rules rejection. Additionally, we can sort client-side on the small filtered result set to avoid needing to define complex composite indexes on Firestore.
**Action:** Always verify matching security rules constraints (like user ownership/assignment) in queries, and use client-side sorting on filtered lists to avoid index overhead.
