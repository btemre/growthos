## 2026-05-23 - Server-side Filtering for Related Entity Tasks
**Learning:** Subscribing to universal task filters (e.g., `subscribeTasksForUser`) inside detailed sub-pages (like `LeadDetailClient`) fetches all tasks assigned to the user (or all tasks in the system for admins), and filters them locally. Creating a scoped Firestore helper `subscribeTasksForRelated` with equality checks (`relatedType` and `relatedId`) filters the tasks directly on the server-side, reducing data transfer and preventing unnecessary re-renders when unrelated tasks change.
**Action:** When working with detailed sub-pages that show related documents (e.g., tasks or activities), write scoped server-side filters instead of fetching all documents and filtering on the client. Sort descending on the client side using a `.sort` function to satisfy ordering requirements without needing complex custom Firestore composite indexes.
