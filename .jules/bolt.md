## 2025-07-29 - [Optimizing Calendar rendering complexity from O(D * E) to O(D + E)]
**Learning:** Performing array operations like `.filter(...)` with complex logic (such as date comparison helpers like `isSameDay`) directly inside JSX `.map(...)` render loops creates a significant O(D * E) bottleneck, where D is the calendar grid days (~42) and E is the total count of events. This becomes extremely slow as the quantity of tasks/leads increases.
**Action:** Pre-group events into a Map keyed by a simple formatted string key (e.g., `"yyyy-MM-dd"`) in a single $O(E)$ pass inside a `useMemo` hook, then perform O(1) Map lookups in the day render loops. Also, memoize structural elements like the `days` grid array themselves to avoid redundant allocations on every component render.
