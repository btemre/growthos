## 2025-03-05 - [Kanban Board Card & Custom Hook Memoization]
**Learning:** Re-renders on drag-and-drop boards are easily triggered by parent state changes (such as drag operations, active states, or stage updates). Components like `LeadCard` or `DealCard` that render inside these boards must be memoized using `React.memo` to avoid cascade re-renders of the entire board's list items. Furthermore, custom hooks (such as `useUserDirectory`) providing callbacks and utilities to these cards must return stable references via `useCallback` and `useMemo` to ensure that standard shallow dependency comparisons inside `React.memo` can successfully skip renders.
**Action:** Always verify if hooks consumed in frequently re-rendering board/list cards are return-stable, and memoize list card components that accept stable primitive props.
