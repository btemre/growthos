## 2025-02-18 - [TodayKey Pattern to Stabilize Date Dependencies in useMemo]
**Learning:** Instantiating newly created `Date` objects (like `new Date()`, `startOfDay(new Date())`, etc.) inside a React component render body and listing them as dependencies of `useMemo` triggers a cache miss on every single render. Since JavaScript `Date` object instances never equal one another via strict comparison (`===`), the `useMemo` is completely bypassed and runs on every render.
**Action:** Extract a stable string key (e.g., `format(new Date(), "yyyy-MM-dd")`) in the render body, pass only the string key as a dependency of `useMemo`, and perform all dynamic `Date` calculations inside the memoized function body.
