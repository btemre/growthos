## 2025-08-05 - Custom Select and Button Loading State Accessibility
**Learning:** Custom components built on Radix or Base UI (such as SelectTrigger) do not automatically inherit or link with outer standard HTML <Label> elements unless programmatically associated via matching `id` and `htmlFor` attributes. Additionally, rendering loading indicators (such as Loader2Icon) inside button components without using React Fragments allows CSS flex-gap attributes on the parent to naturally position and gap the sibling DOM elements correctly without DOM flattening or rendering quirks.
**Action:** Always programmatically associate custom SelectTrigger elements with their form Labels using matching id and htmlFor attributes. Ensure visual loading animations inside core buttons list elements directly without Fragments to preserve CSS flex layouts cleanly.
