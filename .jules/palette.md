## 2026-08-10 - Enhancing Localized Export Actions & Interactive Sensory Feedback
**Learning:** For client-side data compilation (such as exporting dynamic CSV reports or complex sheets), the absence of visual transition states leads to repetitive clicking and confusion. Even when operations compile quickly on the client, introducing a simulated/active transition window (e.g., 500-800ms) with a spinner and state modification provides a powerful cognitive feedback loop. Furthermore, screen readers require specific, localized action readouts (e.g., "Rapor verilerini CSV dosyası olarak indir" instead of simple English labels) to offer an equivalent, barrier-free user experience.
**Action:** When creating any client-side file compilations or async data extractions, always wrap them in a brief interactive loading hook paired with detailed, localized ARIA attributes to prevent double-submits and ensure solid accessible feedback.
